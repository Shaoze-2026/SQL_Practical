# Project Competencies
## 📊 Analytical Skills
  🧮Aggregation
  Use COUNT, AVG, and GROUP BY to summarize data.

  🔍 Filtering
  Apply WHERE, LIKE, and BETWEEN to filter records.

  📊 Sorting
  Use ORDER BY to sort results.

  🎯 Limiting
  Use LIMIT to restrict the number of returned rows.

  🔗 JOINs
  Use JOIN to combine related tables.

  🌍 Population Analysis
  Analyze population trends using aggregated data.

  👥 Demographic Comparisons
  Compare different demographic groups to identify patterns.

## 🔐 Database Maintenance & Security
  🔑 Primary Key Constraints
  Ensure each table has a unique identifier for its records.

  🔗 Foreign Key Relationships
  Link tables together to maintain relational integrity.

  🚫 NOT NULL Constraints
  Prevent missing values by requiring data in specific columns.

  ✔️ Data Validation
  Apply rules to ensure data is accurate and meaningful.

  💾 Backup Planning
  Prepare regular backups to protect data from loss.

  🔐 Access Control
  Restrict who can view or modify data based on permissions.

  🛡️ Data Encryption Awareness

## 🎯 Core Skills Demonstrated
  🧱 Relational Database Design
  Design structured tables and relationships to ensure efficient data organization.

  🧮 SQL Query Writing
  Write SQL queries to retrieve, filter, and analyze data effectively.

  🗂️ Data Modelling
  Create logical data models that represent real‑world entities and their relationships.
